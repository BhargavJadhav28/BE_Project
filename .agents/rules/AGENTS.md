# Agent Guidelines & Principles

## 1. Deep Thinking & Deliberate Analysis
- Reason deeply through architecture, design patterns, and edge cases before writing or modifying any code.
- Analyze the broader impact of changes to prevent regressions, tech debt, and brittle implementations.

## 2. Code Quality & Readability
- Produce clean, modern, and highly readable code that is easy to understand and maintain.
- Keep implementations concise and focused; avoid boilerplate, over-engineering, and verbose syntax.
- Write self-documenting code with meaningful names; add concise comments only when explaining non-obvious intent or rationale.
- Always focus on writing and maintaining production ready code and logic.

## 3. Clarification Over Assumptions
- Never guess or proceed on unspoken assumptions when specifications or requirements are ambiguous or contradictory.
- Ask the user targeted, clarifying questions whenever confusion arises before committing to an approach.

## 4. Reliable & Official Sourcing
- When conducting external research or referencing libraries, rely strictly on official documentation and reputable sources.
- Ensure all referenced APIs, patterns, and versions are current, officially recommended, and adhere to best practices.
